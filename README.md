🚦 Projeto Semáforo

📌 Sobre o projeto

Este projeto consiste na simulação de um semáforo utilizando a plataforma Tinkercad, como parte do meu processo de aprendizagem na área de Ciência da Computação.

O objetivo é representar o funcionamento de um sistema de sinalização de trânsito, explorando conceitos básicos de circuitos eletrônicos e lógica de funcionamento.

🎯 Objetivos

- Compreender o funcionamento de um semáforo.
- Explorar conceitos básicos de eletrônica e circuitos.
- Desenvolver habilidades de raciocínio lógico.
- Aplicar conhecimentos práticos por meio de uma simulação.

🛠️ Ferramenta utilizada

- [Tinkercad](https://www.tinkercad.com/) — plataforma utilizada para a criação e simulação do projeto.

🚥 Funcionamento

O projeto simula a sinalização de um semáforo, representando os estados das luzes de trânsito:

- 🔴 **Vermelho:** indica parada.
- 🟡 **Amarelo:** indica atenção.
- 🟢 **Verde:** indica passagem permitida.

📚 Aprendizados

O desenvolvimento deste projeto contribui para o aprendizado de conceitos relacionados à lógica, à eletrônica básica e à simulação de sistemas, além de proporcionar uma oportunidade de aplicar conhecimentos na prática.
